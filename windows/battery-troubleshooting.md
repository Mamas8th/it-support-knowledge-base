# Windows Battery Troubleshooting

## Check Battery Health:
- Generate power report by typing into the command propmt this command "powercfg /batteryreport". Then press enter 
- Battery report will be generated as an html file
- Review the battery capacity at design and current fill charge
- The battery report also contains details on the current      battery health


## Check battery usage:
- Open windows taks manager(search in applications; or right click the start menu and clikc Task manager)
- Check for applications that are using the most resources(CPU, Memory etc)
- If these applications are not in use, close them. Open them when needed
- 

## Adjust Power Settings:
- Click on the battery in the task bar or search for battery in the Settings app
- Check if battery is set to best perfomance, balanced or battery saver
- Choose the best option based on the current battery performance; taking note of the applications that need to be run currently

## Contacting IT Support:
- In a situation when battery is physically damaged or swelled, please do not troubleshoot yourself. Immediately report to IT 
- Immediately report sudden shut downs to the IT support team for assisnatance
- If you follow all the steps above and battery performance on your device is still bad, report to IT Support for assistance
